# Evaluation

The evaluation command reports AUROC and average precision from continuous image scores, and accuracy, precision, recall, F1, confusion counts, false-positive rate, and true-positive rate at the stored normal-calibration threshold. Pixel AUROC, average precision, Dice, and IoU use an independently calibrated normal-pixel threshold. Anomalous test records without masks are omitted from pixel metrics; normal records without masks are treated as all-zero masks. AUROC and average precision are undefined for one-class test data and are emitted as JSON `null` in that case.

For a binary confusion matrix, precision is `TP/(TP+FP)`, recall/TPR is `TP/(TP+FN)`, FPR is `FP/(FP+TN)`, F1 is the harmonic mean of precision and recall, and accuracy is `(TP+TN)/N`. Pixel Dice is `2TP/(2TP+FP+FN)` and IoU is `TP/(TP+FP+FN)`. The workflow also reports image-level bootstrap intervals, synchronized per-image latency summaries, prediction-level CSV/JSONL, visualized errors, and paired comparisons over identical held-out sample IDs. Pixel-level confidence intervals and PRO are not implemented. Treat observed metrics as a category-specific held-out benchmark, not a general deployment guarantee.
